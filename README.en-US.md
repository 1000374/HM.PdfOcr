# HM.PdfOcr
This tool is primarily used to extract PDF content (including editable and non-editable PDFs). Non-editable PDFs can be converted into searchable (dual-layer) PDFs to enable copying (preserving the original format), or converted directly into text PDFs (original format not preserved).
Currently, image extraction is limited to extracting all images.

### This project is created based on .NET Framework 4.8. PaddleSharp can only be used under x64, and files can only be used on 64-bit systems.

*For content extraction details, see: https://www.cnblogs.com/xiaohemiao/collections/11166

## The following open-source libraries are used, thanks:
*PdfiumViewer for PDF preview and editable PDF extraction: https://github.com/pvginkel/PdfiumViewer 

*PDFsharp for generating PDFs: https://github.com/empira/PDFsharp 

*PaddleSharp for image OCR recognition: https://github.com/sdcb/PaddleSharp
